## How to read the results

- Policy-only evidence should never get FULL on a runtime control (S-series). If it does, the rubric is too lenient for this model.
- The excerpt should be a real phrase from the block. If a validation flag says the excerpt was not found, the model invented or paraphrased it.
- The "before accepting, ask" question is a good check on whether the model understood the gap — for 1a it should ask for the inventory record, for 3b whether any assessment has actually been completed.
