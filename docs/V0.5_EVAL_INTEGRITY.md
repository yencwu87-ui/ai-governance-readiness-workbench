# v0.5 Evaluation Integrity

The scored corpus is a governed artefact. `eval/active_set.json` records the exact SHA-256 and case count for `eval/golden_set.jsonl`.

The diagnostic set is designed to measure the three-way sufficiency boundary, not to mimic live prevalence. It therefore keeps the three classes visible and includes real-evidence Full cases. Real-evidence fixtures are repository-controlled evidence files, not external client data.

Historical score results are retained under `eval/history/`. The readiness status only accepts a score whose `eval_set_sha256_12` equals the current corpus hash. `results[-1]` is not authoritative for current readiness.

For model promotion, evaluate at least:
- exact accuracy
- real-evidence accuracy
- adjacent accuracy
- over-credit rate
- under-credit rate
- refusal and quarantine rates
- majority-class baseline margin
- per-class precision/recall/F1
- balanced accuracy
- real-evidence Full-case support

A model that does not exceed the majority baseline or cannot reliably reach Full on applicable Full cases is not promotion-ready.
